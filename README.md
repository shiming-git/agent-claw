## 项目发布说明

`agent-claw` 是一个 **AI Agent 智能体平台**：你用 **Web 浏览器**完成主要操作；程序以**本地后台常驻服务**运行，负责会话、任务执行与模型调用。产品交互与信息展示采用统一的布局与呈现方式，便于上手使用。

### 仓库地址（下载）

- GitHub：[shiming-git/agent-claw](https://github.com/shiming-git/agent-claw)
- Gitee：[librarycodes/agent-claw](https://gitee.com/librarycodes/agent-claw)

### 1) 我拿到发布包后怎么用？

1. 解压发布包（保持目录结构不变）。
2. 启动程序（双击运行，或用命令行启动）。
3. 浏览器打开 Web 地址：`http://127.0.0.1:18080/`
4. 首次打开页面时，按提示输入 Token 即可进入。

### 2) 第一次启动需要做什么配置？

只需要编辑发布包同级的 `config.json`：

- `**service_token`**：前端首次打开会要求输入该 Token（用于访问鉴权）。
- `**models[]`**：**模型接入能力（重点）**。平台支持接入多家不同的大模型 API：**只要是 OpenAI API 兼容的接口**，通常都可以接入使用。
  - `base_url`：模型服务地址
  - `model_name`：模型名称
  - `api_key`：访问密钥

详见：[首次运行与配置](first-run-and-configuration.md)

### 3) 功能入口在哪里？

打开 Web UI 后常用入口（菜单）：

- **扩展**：管理 Skills / MCP /  Agents
- **计划**：查看与管理定时任务（列表/详情/执行记录）
- **设置**：配置模型与密钥（本质是编辑 `config.json`）
- **反馈**：通过邮件反馈

### 4) 主要功能介绍

- **鉴权（无账号体系）**：不做注册登录，使用 `config.json` 的 `service_token` 作为访问令牌；无 Token / Token 无效则拒绝访问。
- **会话管理**：新建会话、历史会话列表、上下文延续。
- **任务与执行视图**：在对话中展示计划/步骤、工具调用、错误与重试。
- **两种工作模式（核心）**：
  - **单智能体：Agent Pool**：单个智能体的工作空间（权限面较大），也可以在这里创建新的工作组（Agent Team）。
  - **多智能体协同：Agent Team（工作组/项目）**：团队协作（Team Lead + Teammates），强调隔离与只在组内活动。
- **模型与 Agent 配置（核心）**：每个 Agent 都可以独立配置“提示词 + 使用的大模型”。
- **扩展能力（按需加载）**：
  - **Agents**：添加/管理文件型 Agents 或自定义智能体，让不同场景用不同的“角色与能力组合”来完成任务。
  - **Skills**：以 Markdown 形式沉淀能力说明/流程；按需读取与使用。
  - **MCP**：对接外部 MCP Server，按需连接并调用远端工具。
  - **计划（定时任务）**：创建定时任务、立即执行一次、查看执行记录（便于自动触发流程）。

> 注：Gateway（多平台接入）为可选能力；若你的发布包未启用该能力，可先忽略。

### 5) “工具（tools）”是什么？

在本平台里，“工具（tools）”指的是 **智能体内置的动作能力**（用来“真正做事”）。常见包括：

- **文件与资料**：读取/写入本地文件、整理内容、生成输出
- **命令执行**：运行系统命令或脚本，把结果回传到对话中
- **信息查询**：按需发起网络请求/检索（若当前发布包启用该能力）
- **结构化处理**：将信息按固定格式提取/校验/转换（便于后续自动化）

> 提示：Skills / MCP / Agents / 计划任务属于“扩展能力/入口”，用于让智能体获得更多资源或连接更多系统；真正执行动作时，仍由内置 tools 来完成。

### 6) 怎么才能让 Agent 自动使用这些能力？

你不需要学习“怎么调用工具”。在对话里 **直接用自然语言把需求说清楚**（你要做什么、输入是什么、希望输出什么、有什么限制），智能体会自动选择并使用合适的内置工具来完成。

推荐你这样说（示例）：

- **闹钟/定时提醒**：“帮我建一个每天 9 点提醒我的任务，并告诉我怎么关闭它。”
- **修改文件**：“把这份文档里所有的错别字改掉，并把改动点列出来。”
- **创建协作团队（Agent Team）**：“帮我创建一个新的 Agent Team，取名为‘产品发布’，并把我需要添加哪些成员说清楚。”
